# v1.0.1 - Zenodo Metadata Release

Repository: https://github.com/dawidkucharski/optical-tactile-surface-benchmark

This patch release adds citation and Zenodo metadata for DOI archiving of the manuscript-facing reproducibility package.

## Added

- `CITATION.cff` with citation metadata for GitHub and citation managers.
- `.zenodo.json` with Zenodo deposition metadata.
- Updated release checklist instructions for DOI archiving.

## Release Scope

The release remains the public reproducibility package for the retrospective optical-vs-tactile surface roughness benchmark. It includes scripts, configuration files, manuscript and supplement sources, generated CSV outputs, tables, and figures. Raw `.sur` / `.SUR` surface files remain excluded from the public repository.

## Zenodo Step

Enable the repository in Zenodo GitHub integration before publishing this release. Zenodo should then archive the release and mint a DOI for `v1.0.1`.
